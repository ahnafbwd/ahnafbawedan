Changes are saved locally. To sync with GitHub Pages or external systems:

  1. Use "Export JSON" to download your current projects
  2. Replace assets/data/projects.json with the downloaded file
  3. Commit and push to GitHub to update your live portfolio
  4. Use "Reload" to sync with the updated file
